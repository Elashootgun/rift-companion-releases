# Rift Companion

Windows downloads and updates for Rift Companion.

## Install

Open [the latest release](https://github.com/Elashootgun/rift-companion-releases/releases/latest) and download the `RiftCompanionSetup-<version>.exe` installer. Python is bundled.

Your accounts, imported games, comfort ratings, and settings are stored separately from app files. Updates preserve them.

## Updates

The desktop app checks for updates after launch. Available updates download in the background. Choose **Update and restart** when ready, or close and launch the app again through its shortcut. The app keeps the previous version for startup recovery.

## Existing ZIP users

Install the desktop app, then use **Import old folder** to copy your saved data from the old Rift Companion folder.

This repository hosts release files only. It contains no personal accounts, match history, or source-code project.

The first desktop release is being prepared. Downloads become available once that release is published.
